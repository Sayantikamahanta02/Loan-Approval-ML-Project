# Loan-Approval-ML-Project

## Overview
This Machine Learning project predicts whether a loan application will be approved based on applicant information such as income, education, marital status, loan amount, and credit history.

## Technologies Used
- Python
- Pandas
- Scikit-learn

## Machine Learning Model
- Random Forest Classifier

## Features
- Data Cleaning
- Feature Engineering
- Data Preprocessing
- Model Training
- Loan Approval Prediction

## Project Goal
To automate the loan approval process and help financial institutions make faster decisions.
